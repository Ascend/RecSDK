# Supported tags

A full list of tags that are supported with RecSDK.

> The chip identifier in the tag is determined by the `CORE_TYPE` build argument passed when building the image: `CORE_TYPE=a2` produces the `910b` tag, `CORE_TYPE=a3` produces the `a3` tag, and `CORE_TYPE=a5` produces the `950` tag. One Dockerfile can produce images for all three chip platforms. For build commands, container startup, and environment switching instructions, see [OVERVIEW.md](https://gitcode.com/Ascend/RecSDK/blob/develop/docker/OVERVIEW.md).
