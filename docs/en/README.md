# Welcome to Rec SDK

<div style= "text-align:center;">
  <span style="font-size:2.5rem">Rec SDK</span>
</div>

Rec SDK addresses the application scenario requirements of search, recommendation, and advertising (SRA) model training. It provides an SRA framework based on the Ascend platform that supports large-scale SRA scenarios, facilitating efficient training of SRA models. This docs repository provides related guidance documents for Rec SDK.
