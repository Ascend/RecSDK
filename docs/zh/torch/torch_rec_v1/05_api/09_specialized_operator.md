# 自定义算子<a name="ZH-CN_TOPIC_0000002452078416"></a>

在推荐训练中，存在部分算子无NPU实现，或已有NPU实现但性能较差，不能满足推荐训练需求。Rec SDK Torch提供了以下[表1 自定义算子列表](#table23231336143616)，用于支持/加速推荐模型NPU训练。

其中，部分自定义算子已绑定到开源API（将开源API的backend实现转发到NPU），在导入Rec SDK Torch软件包后，可直接通过开源API调用到自定义算子。其余算子则需通过PTA层注册的mxrec模块进行调用。

> [!NOTICE]
>
> 1. 自定义算子为高性能计算，用户调用自定义算子时需自行确保输入的参数满足算子约束条件、参数类型、参数shape等要求，否则可能会出现数组越界、显存不够等问题导致算子执行失败。
> 2. 由于每个自定义算子的参数列表、类型、约束各不相同，且各个算子README中已有详细介绍，因此本章节不再赘述，仅列举自定义算子列表。**如需查看各自定义算子的详细参数、部署和调用方式，可参考自定义算子列表中的算子名称超链接跳转查看算子对应README**。

自定义算子列表中“是否支持通过开源API调用”列各个值的含义说明：

- 是：表示该算子存在对应的开源API，且已绑定到开源API，可通过开源API调用，同时也支持通过PTA层注册的mxrec模块调用。
- 否：表示该算子存在对应的开源API，但未绑定到开源API，仅支持通过PTA层注册的mxrec模块调用。
- NA：表示该算子无对应的开源API，仅支持通过PTA层注册的mxrec模块调用。
