# 功能

将输入数据(input，三维Tensor)根据指定长度参数（seq_lengths，一维Tensor）进行第二维的逆序操作。

# 算子实现原理

```python
import numpy as np


def reverse_sequence_3d_np(input, sql_lengths):
    batch_size, max_seq_len, data_dim = input.shape
    out = input.copy()
    for b in range(batch_size):
        len_b = sql_lengths[b]
        if len_b > 0:
            out[b, :len_b] = input[b, :len_b][::-1]  # 只翻转前 len_b 个向量
    return out


input_data = np.random.randn(3, 5, 4).astype(np.float32)
sql_lengths_data = np.array([3, 3, 4])
output = reverse_sequence_3d_np(input_data, sql_lengths_data)
print(input_data)
print(sql_lengths_data)
print(output)
```

# 算子输入与输出
|  名称  |  输入/输出  |  数据类型  |  数据格式  |  范围  | 说明                                               |
|  ---- |  ---- |  ----  |  ----  |  ----  |--------------------------------------------------|
|  input | 输入 | bfloat16/float16/float32 | [batch_size, max_seq_len, data_dim] | batch_size范围:[1,10240]，max_seq_len范围：[1,102400]，data_dim范围：[16,1024]且data_dim需要是16整数倍  | 仅支持三维tensor。逆序是基于max_seq_len所在维度进行逆序。            |
