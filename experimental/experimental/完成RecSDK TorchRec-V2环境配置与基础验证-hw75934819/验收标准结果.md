| 模板要求 | 实际 | 状态 |
|----------|------|------|
| **现状问题** | 容器内 Python 3.11 实际安装在 `/usr/local/python3.11.0/`，`libpython3.11.so.1.0` 在 `/usr/local/python3.11.0/lib/`，但该路径未被加入系统 `LD_LIBRARY_PATH`，首次进入容器直接使用 `python3` 必然报错 | ✅ |
| **优化方案** | 1) Dockerfile 或容器启动脚本固化 `export LD_LIBRARY_PATH=/usr/local/python3.11.0/lib:$LD_LIBRARY_PATH`<br>2) 同时建议自动 `source /opt/buildtools/torch_v2_pt2.7.1/bin/activate`<br>3) 快速入门文档补充本步骤 | ✅ |
| **附件** | ① `python3: error while loading shared libraries: libpython3.11.so.1.0: No such file or directory` 终端截图<br>② `find / -name "libpython3.11.so*"` 实际路径截图<br>③ 容器默认 `/etc/profile.d/` 无追加 Python 路径的脚本验证 | ✅ |
